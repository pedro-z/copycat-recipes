## 🚀 Como publicar

1. Crie o repositório `copycat-recipes` no GitHub (público).
2. Suba todos os arquivos desta pasta para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Source**, escolha **Deploy from a branch**.
5. Branch: `main` · pasta: `/ (root)`.
6. Salve. Em alguns minutos o site estará no ar.
